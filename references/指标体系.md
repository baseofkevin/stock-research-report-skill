# 指标体系速查（用于企业信息解读报告）

> 完整版见《企业财务分析指标体系手册》。本文件是**执行报告时的精简版**，
> 但已覆盖手册全部 14 章的可执行部分——**凡是手册里给了表、给了阈值、给了口径的，
> 这里都必须能查到；查不到的才允许写「暂无披露」。**
>
> 三条铁律：**现金流 > 利润；趋势 > 时点；结构 > 总量。**
> 章节编号与手册十四章对应，便于回查原文。
> 每一项指标出自哪张报表的哪一格：本文件每节标题后已标注手册章节，
> 具体**字段名 → 指标**的机器可读映射见 `westock-接口.md` 第三节和第六节。

## 0. 七步研判流程（报告的主干，每步都要留痕）

```
1 验真伪   → §6 现金流：OCF 是否为正、净现比在哪一档、扣非净现比
2 看趋势   → §2 三项改善信号 + §5 成长四象限 + §4 毛利率 5 年序列
3 查质量   → §4 扣非缺口、§5 三费、§7 应收/存货/在建/商誉/其他应收
4 排雷     → §1 四项安全判定 + §8 有息负债 + §12 排雷 25 条逐条过
5 定性质   → §4 ROE/ROA/ROIC 三件套 + §9 护城河层
6 交叉验证 → §10 科目变动矩阵：先定象限，再逐行核对每个科目讲不讲得通
7 问价格   → §3 估值：PE 梯度 + PB + PEG + 历史分位 + §13 打分卡收口
```

**一票否决规则**：第 1 步（现金流）或第 4 步（安全）任一高危 → 直接否定；
第 6 步故事讲不通 → 直接否定，不必再算估值。

**数据纪律**：任何一项拿不到数据的指标，判定写「无数据」，**打分卡该项填 `null`（不可评）
并从分母剔除**（见 §13 缺项处理）——**绝不记 0 分**（0 分是「中性」，会把数据不全的公司判成变差），
也绝不凭印象补数字。

## 1. A 类硬判定 · 四项安全指标（手册第一章 / 第七章）

### 1.1 现金短债比 —— 短期会不会断气

`货币资金 ÷ (短期借款 + 一年内到期非流动负债)`

| 阈值 | 判定 |
|:--:|---|
| ≥ 1.0 | 正常 |
| < 1.0 | 紧张 |
| < 0.5 | **高危**（一票否决项） |

- 分子建议用「货币资金 + 交易性金融资产」，并剔除受限的票据保证金。
- **口径陷阱（实测）**：WeStock 的资产负债表**没有**「短期借款 / 一年内到期非流动负债」明细，
  只有 `InterestBearDebt`（有息负债合计）。取不到细分时用「货币资金 ÷ 有息负债」做**保守替代**，
  并在报告里写明「本比率用有息负债合计，比短期口径更严」；仍算不出就判「无数据」。
- **静态比率会被时点数据美化**（西部超导流动比率 2.43 看着健康，但经营现金流已转负），
  必须与现金流趋势一起看。

### 1.2 净现比 —— 利润的含金量

`净现比 = 经营活动现金流净额 ÷ 归母净利润`

| 区间 | 判定 |
|:--:|---|
| > 1.0 | 优秀，甚至收回往期欠账 |
| 0.7 ~ 1.0 | 健康 |
| 0.3 ~ 0.7 | 警惕，利润与现金脱节 |
| < 0.3 或负 | 危险，可能收入虚增 / 提前确认收入 |

- 交叉验证：**扣非净现比 = 经营现金流 ÷ 扣非净利润**。
- 连续多年偏低 = 商业模式本身赚不到现金；单年骤降要分是回款慢还是支出端占用增加。
- 年报口径：**最近 2 个年报均 < 0.5 → 高危**；只有最新一年 < 0.5 → 关注。负值也算 < 0.5。

### 1.3 应收增速差 —— 是不是靠赊账换增长

`应收增速差 = 应收账款增速 − 营业收入增速`

- 最近 2 个年报均 > +15 个百分点 → **高危**
- 只有最新一年 > +15 个百分点 → **关注**

⚠️ **必看的误报修正**：营收塌方型企业，应收绝对额没涨、营收大跌，算出来的差值反而大幅为正。
**必须回看应收绝对额**——没涨就不是放宽账期，是需求萎缩，不构成垫资风险。
（实例：钒钛股份应收 1.36 亿 → 1.32 亿，营收 −32.7%，机械口径 +32.7pct，实质无风险。）

配套排查：应收占收入比、周转天数是否年年拉长、前五大客户集中度、1 年以上账龄占比、
坏账计提政策是否显著松于同行、应收账款是否突然大量转为应收票据（科目腾挪）。

### 1.4 速动比率 —— 极端情况下的变现能力

`(流动资产 − 存货) ÷ 流动负债`　　`< 0.7 → 关注（计 1 分）`

分子建议**再剔除其他应收款**——它是"名义流动资产、实际回不来"的典型。

### 1.5 其余两项安全指标

| 指标 | 公式 | 判读 |
|---|---|---|
| 流动比率 | 流动资产 ÷ 流动负债 | < 1.5 留意（重资产可放宽） |
| 营运资本 | 流动资产 − 流动负债 | **为负 = 技术性资不抵债边缘** |

## 2. A 类硬判定 · 三项改善信号（手册第一章）

### 2.1 ① 毛利率环比改善

`GM = (营业收入 − 营业成本) ÷ 营业收入`

三条同时成立才算「是」，否则「否」，数据不足则「无数据」：

1. 最近 2 个单季严格递增：`GM[t−1] < GM[t]`
2. 最新一季营收环比不为负：`Rev[t−1] ≤ Rev[t]`（排除靠砍业务瘦出来的好看）
3. 最新单季高于上年同季：`GM[t] > GM[t−4]`（剔除季节性）

⚠️ `GrossIncomeRatio` 接口字段是**累计口径**，必须先倒挤单季营收和单季成本再算，不能直接当单季用。

### 2.2 ② 合同负债 / 订单增长

`订单代理 = 合同负债 + 预收款项`
`同比 = (本期 ÷ 上年同季 − 1) × 100`；`规模 = 本期 ÷ 营业总收入 TTM × 100`

**同比 ≥ 20% 且 规模 ≥ 2% → 是；否则 → 否。**

时点值，要看 3–4 个季度趋势；经销商打款性质的预收要打折看待。
WeStock core 字段集通常不返回该科目 → 置「无数据」，并说明需查财报附注。

### 2.3 ③ 经营现金流

满足其一即为「是」：

1. `OCF_TTM > 0`，且
2. 满足以下任一：`OCF_TTM` 由负转正 / `NP_TTM ≤ 0` / `OCF_TTM ÷ NP_TTM > 1`

## 3. 估值层（手册第二章 / 第十三章）

### 3.1 三种 PE 的分母对照

| 指标 | 分母（净利润） |
|---|---|
| 静态 PE | 上一年度年报净利润 |
| 滚动 PE（TTM） | 最近 12 个月净利润（最常用） |
| 动态 PE | 预测的年度净利润（或按最新季度年化） |

⚠️ **亏损年度的静态 PE 是负数**，不可用于判断贵贱（实例：钒钛股份 −263.85）。
只能看 PB 和 TTM，并写明「静态 PE 已失真」。

**三种 PE 的梯度解读**（这是最有辨识度的一招）：

| 梯度 | 含义 |
|---|---|
| 静态高、滚动低 | 最近确实赚更多了，业绩在改善 |
| 滚动高、动态低 | 机构预期未来大幅改善——**预期不是事实** |
| 静态低、动态高 | 机构预期未来利润**下滑** ⚠️ |

反推隐含预期：`隐含预期净利 = 总市值 ÷ pe_fwd`。

### 3.2 PB

- **周期股 / 金融股 / 资源加工型企业优先看 PB**，PE 在周期顶部会假便宜。
- 要算**经营性 PB**：剔除理财和商誉后再算 PB，才是真安全垫。
- PB 低但净资产里大量是理财或未分配利润 → **低 PB 的安全垫是假的**。

### 3.3 PS / PEG / 股息率

| 指标 | 用法 |
|---|---|
| PS | 暂时不盈利但营收高增长时用，**必须配合净利率看** |
| PEG | 接近 1 匹配，> 1.5 偏贵，< 0.8 偏便宜；**仅适用稳定成长股** |
| 股息率 | 高分红是现金流的硬证据；**高股息 + 低 ROIC = 现金牛而非成长股** |

**PEG 的三个缺陷**（别当万能钥匙）：对增速预估不准；PE 波动大易失真；忽略资产自有价值。
→ 更科学的做法是**用 ROE 对 PE 和 PB 建立统一模型**。

### 3.4 PE / PB 组合四象限

| 组合 | 含义 | 处置 |
|---|---|---|
| PB 低 + PE 低 | 资产质量没问题时 → **安全边际最高** | 重点筛（先排资产有毒） |
| PB 高 + PE 低 | 市场认可资产，当前盈利被低估 | 找盈利反转的可能 |
| PB 低 + PE 高 | 资产便宜但盈利弱 | 要判断盈利能不能恢复 |
| PB 高 + PE 高 | 估值泡沫，或刚计提完大额减值 | 回避 |

**实操建议：以 PB 为资产分析基础，PE 作为议价填充分析。**
某年高 PE + 低 PB → 当年盈利"打摆子"，要分析原因；某年低 PE + 高 PB → 要考核盈利可持续性。

### 3.5 历史分位

PE / PB / PS 处于 **近 5–10 年区间 < 20% 为低估，> 80% 为高估**。
周期股看 PB 分位（实例：钒钛股份 PB 1.96 为五年最低）。

**样本区间规则（别拿次新股泡沫当分母）**：

- 上市满 5 年 → 用近 5 年（或 10 年）全样本，分位 = 低于当前值的交易日占比；
- **上市不足 5 年 → 用「上市以来」全样本，并在报告里写明样本起点与交易日数**
  （例：「PE 分位 19.3%，样本为 2021-12-16 起 1176 个交易日」）；
- 上市不足 1 年 → **不给分位**，直接写「样本不足，不做历史分位判断」；
- 分位怎么算（采样频率、限频、算法）见 `references/westock-接口.md` 第七节；
- **PE / PB / PS 三个分位必须一起看**：三个都在低位 → 全面便宜；只有 PB/PS 低而 PE 高
  （或反之）→ 说明利润或净资产被扭曲了，要回去查一次性收益与减值；
- 分位只用于「相对于自己的历史贵不贵」，**不能替代绝对估值**——
  一家从 106 倍 PE 跌到 32 倍的公司，分位低不代表便宜。

### 3.6 ROE 与增长的数学关系（为什么高 ROE 本身就隐含成长）

`ROE = E ÷ B`（E = 净利润，B = 净资产）

- 若**不分红**：前一年的 E 累进到后一年的 B。维持 ROE 不变，就要求新一年的 E 伴随 B 同比例增长。
- 若**完全分红**：新一年 B 不增长，E 只要不衰减就够。

→ **持续高 ROE 且不分红的公司，利润必须年年增长才能维持 ROE**。
这条可以反推"业绩增速是否可持续"。注意：**零分红 + 低 ROE 的公司不受这条约束**
（实例：钒钛股份零分红、ROE 2.61%，所以它的净利润可以长期趴着不动）。

### 3.7 对「P = PE × E」的批评

PE 估值法的先天缺陷：PE 是单年度数值，**连续性差、波动性高**，
对"盈利长期稳定"要求很高——但"稳定"恰恰最难。

**更完整的公式**：`PB = f(ROE, g, G, r)`，
其中 g 是股市必要收益率，G 是企业业绩成长速度，r 是分红率。

> 买股票 = 买公司的有效净资产 + 未来的盈利。**PB 对有效净资产的溢价，就是靠未来盈利扩充的。**

**戴维斯双击的两个来源**：业绩增速快 + PB 低；业绩增速低但 ROE 高 + PB 低。

## 4. 盈利质量层（手册第三章）

### 4.1 毛利率 —— 护城河的第一指标

**永远拆分看，不要只看整体。** 规则是**算「各业务毛利额占比」，而不是只看毛利率数字**：

| 陷阱 | 实例 |
|---|---|
| 高毛利业务占比很低 = 等于没有 | 蓝帆医疗：心血管器械毛利 64% 却只占收入 30%，真正撑营收的是毛利 20% 的一次性手套 |
| 盈利全靠一小块业务撑着 | 恒星科技：占营收 56% 的金属制品毛利仅 7%，占营收 33% 的有机硅毛利 23% |
| 高毛利业务没到规模摊薄临界点 | 当虹科技：车载毛利 67.51%、机器人 74.81%，但收入仅 2717 万 / 1002 万 |

### 4.2 净利率

`净利率 = 净利润 ÷ 营业收入`。**净利率持续 < 3% 的制造业**，一旦上游涨价或下游压价立刻亏损。

### 4.3 扣非净利润 ⭐

`扣非净利润 = 归母净利润 − 非经常性损益`
（非经常性损益包括：政府补助、资产处置、投资收益、公允价值变动、税收返还等）

**数据源对齐**：WeStock 的利润表**直接给** `NPDeductNonRecurringPL`（扣非归母净利润），
单季用 `NPDeductNonRecurringPL_Q`，配套的还有 `ROECut`（扣非 ROE）。
**不用自己拿归母减非经常性去推**——推出来的是估算，接口给的是公告口径。

**归母净利增速 vs 扣非增速的缺口，就是包装的程度**：

- 缺口大 → 靠补助 / 理财 / 处置资产撑利润（厚普股份：净利 +518%、扣非 −51%）
- 扣非占归母 90% 以上 → 干净（钒钛股份 94%）
- **基数扭曲陷阱**：上年亏损时扣非增速会出现 +1790% 这种数字，必须配合现金流看真相

### 4.4 ROE / ROA / ROIC 三件套 + WACC

| 维度 | ROE | ROIC | WACC |
|---|---|---|---|
| **分母** | 净资产（股东的钱） | 股东的钱 + 借的钱 | 股东的钱 + 借的钱 |
| **反映** | 股东资金的回报率 | 全部投入资本的回报率 | 资本的综合成本率 |
| **受杠杆影响** | **高杠杆会虚高** | **剔除杠杆影响** | 杠杆越高成本越高 |
| **一句话总结** | 股东视角的"**分钱率**" | 生意本身的"**赚钱率**" | 资本的"**及格线**" |

- `ROE = 归母净利润 ÷ 平均净资产`。长期 > 15% 优秀，10–15% 良好，< 8% 偏弱。
  **分母用 `SEWithoutMI`（归母净资产）自己算**，接口虽然也回传 `ROE` / `ROIC` / `ROA` 三个现成字段，
  但口径可能含少数股东权益、也可能用期末而非平均，**只能当交叉验证，不能直接抄**。
  报告里两个数差超过 1pct 时，要说明用的是哪一个口径。
  **关键是「连续 5 年稳定」**（5 年是最小考察期）。
- `ROA = 净利润 ÷ 平均总资产`。
- `ROIC = 息税前利润 ×(1 − 税率) ÷ (有息负债 + 股东权益)`。
- **及格线：ROIC > WACC**。资本成本保守取 **5.5%**（对照国债/理财收益），稳健公司可取 6%~8%。
  **ROE 高但 ROIC < WACC = 表面赚钱、实际毁灭价值。**

**三者排序规律（经验，非数学定律）**：

| 情形 | 排序 |
|---|---|
| 正常盈利 | `ROE > ROIC > ROA`（ROIC 居中） |
| 一般亏损 | `ROE < ROIC < ROA`（**排序反转**，ROIC 仍居中） |
| 巨亏 + 高杠杆 | ROIC 可能比 ROA 还大（跑出上限） |
| 无负债 | 三者几乎相等 |

四条支撑逻辑：
1. 盈利时 ROE 最大 —— 分母最小且可能加了杠杆。
2. 亏损时排序反转 —— 都是负数，分母越小（股东权益）亏得比例越惨。
3. 巨亏高杠杆跑出区间 —— 净资产极小而债务极大，ROE 夸张地负，ROIC 与 ROA 分母接近。
4. 无负债三者相等 —— 三个分母几乎一样。

**实操**：拿到三个数先看排序。`ROE >> ROIC` → 杠杆撑起来的，扣分；
三者接近且都高（13.3 / 11.4 / 13.4）→ 无杠杆的高回报，真优秀；`ROE < ROIC` → 处于亏损状态。

### 4.5 杜邦拆解：高 ROE 的三种来源

`ROE = 净利率 × 资产周转率 × 权益乘数`

| 驱动 | 代表 | 评价 |
|---|---|---|
| **净利率** | 茅台 | 护城河强，**最优质** |
| **周转率** | 沃尔玛 | 运营效率高，次优 |
| **杠杆（权益乘数）** | 银行 | **风险最高**，需关注负债质量 |

高低组合：**高 ROE + 低 PE** → 好公司便宜买；**高 ROE + 高 PE** → 可能已被充分定价。

### 4.6 每股收益 EPS（含股本扩张陷阱）

`EPS = 归母净利润 ÷ 总股本`

笔记原话："**它不是衡量财务表现的最重要的指标**，不看现金流量表单看这个数字没有意义。"

⚠️ **股本扩张陷阱**：总股本从 13.7 亿增至 22.3 亿（融资/转增），
股价托底是"股本扩张 + 融资的名义效果，并非资产真实价值"，EPS 被稀释。
→ 必须对照**每股口径**：每股营收、每股经营现金流、每股净资产，才能看穿增发/转增的假象。

## 5. 成长层（手册第四章）

### 5.1 营收增速 —— 一切增长的起点

没有营收增长，利润增长只能靠降本或一次性收益，不可持续。

### 5.2 营收 × 净利 四象限（用来直接定性）

| 营收 | 净利 | 定性 | 实例 |
|:--:|:--:|---|---|
| ↑ | ↑↑ | **量利齐升**（最好） | 新亚强（+ 现金流转好） |
| ↑ | ↓ | **增收不增利**（成本涨价 / 价格战） | 精达股份营收 +29%、净利 +6% |
| ↓ | ↓ | **收缩**（行业下行） | 中密控股营收 −4.25%、净利 −28.07% |
| ↓ | ↑ | **瘦身为盈**（卖资产 / 砍业务，⚠️ 警惕） | 安彩高科剥离 6 家子公司 |

### 5.3 三项费用（销售 / 管理 / 研发）

`费用率 = 该项费用 ÷ 营业收入`；`研发占比 = 研发费用 ÷ 营业收入`

| 观察项 | 正常 | 异常 |
|---|---|---|
| 费用率趋势 | 随规模效应下降或稳定 | 异常上升，费用失控 |
| **费用增速 vs 收入增速** | 费用增速 ≤ 收入增速 | **费用增速 >> 收入增速，效率恶化** |
| 费用结构 | 与业务匹配 | 某单项费用突增，缺乏合理解释 |
| **资本化 vs 费用化** | 会计政策一致 | **突然加大资本化比例，减少当期费用** |

→ 判据：**费用增速 > 营收增速且持续 2 年以上** → 投入没转化为收入。

**四个深层排查点**

1. **费用增速远超收入增速要分性质**：主动投入（研发、渠道，可能长期利好）vs
   被动失控（费用刚性增长、收入停滞）。**前者可以忍，后者必须跑。**
2. **销售费用率异常下降 ≠ 效率提升**：警惕是否延迟确认费用或将费用资本化。
3. **研发资本化游戏（最隐蔽）**：加大资本化比例可以显著提升当期利润，
   **必须跟踪资本化比例的变化趋势**。出来混迟早要还——后续摊销压力更大。
4. **收入与费用的期间匹配性**：收入确认了但销售费用未同步确认 → 跨期调节利润嫌疑。

⚠️ **反向警惕：费用被砍出来的利润**。研发费用降幅大于营收降幅时，当期利润有一块是"省出来的"，
不可持续（实例：钒钛股份研发 4.47 亿 → 2.87 亿 → 年化 1.7 亿，降幅大于营收）。

## 6. 现金流层（手册第五章 · 圣杯）

> 《股市真规则》："经营活动现金流净额是判断一家公司是否发生现金的**圣杯**。"
> 《七个错误》：错误七就是"单纯依靠净利润做分析"。

### 6.1 经营活动现金流净额 OCF
长期为正且增长 = 健康；转负 = 危险。

### 6.2 净现比、扣非净现比
见 §1.2。

### 6.3 自由现金流 FCF

`FCF = 经营活动现金流净额 − 资本开支（购建固定资产、无形资产和其他长期资产支付的现金）`

回答"**维持运转后还剩多少钱能分给股东**"。

### 6.4 三流组合 —— 判定企业处于什么阶段

| 经营 | 投资 | 筹资 | 解读 | 实例 |
|:--:|:--:|:--:|---|---|
| + | − | − | **成熟现金牛**：主业造血，投资回收，还债分红 | 中密控股（高股息） |
| + | −− | + | **扩张期**：主业造血但不够，借钱扩产 | 大洋生物 |
| − | − | ++ | **⚠️ 危险**：主业失血还在投，全靠外部输血续命 | 精达股份（−107%/−51%/+128%） |
| − | −− | + | **烧钱转型**：用融资的钱赌未来 | 厚普股份、智莱科技 |
| − | + | − | **收缩求生**：卖资产还债 | 安彩高科 |

⚠️ **「经营 −、投资 −、筹资 +」是最高危组合**：一旦融资环境收紧立刻断链。

## 7. 资产质量与运营层（手册第六章）

### 7.1 货币资金 / 现金占比

`现金/营收 = 货币资金 ÷ 营业收入`；`现金/总资产 = 货币资金 ÷ 总资产`

**反面陷阱：现金过多也是问题。**
理财占总资产 66.5%、巨额未分配利润趴账 → **"大量现金不知怎么用，本身就是价值损耗"**，
说明行业空间窄、管理层缺乏再投资能力。

### 7.2 应收账款 —— 对下游的议价能力

`应收/营收 = 应收账款 ÷ 营业收入`；`应收周转天数 = 365 ÷ (营业收入 ÷ 平均应收账款)`

- 占总资产比例高（如 22%）+ 下游是强势大客户 → **账期被占用，公司对下游没有议价能力**。
- **银行承兑汇票比纯应收账款安全得多，要区分**（建业股份 6 亿应收多为银承）。

### 7.3 存货 —— 三种结构警示（比总额重要得多）

`存货周转率 = 营业成本 ÷ 存货平均余额`；`存货周转天数 = 365 ÷ 存货周转率`

| 观察项 | 健康 | 恶化 |
|---|---|---|
| 周转天数 | 稳定或缩短 | 持续拉长 |
| 存货增速 vs 收入增速 | 存货增速 ≤ 收入增速 | **存货增速 >> 收入增速，库存积压** |
| 跌价计提 | 计提充分、政策一致 | 计提不足或突然变更政策 |

**结构三分解**（必须落到这一层）：

| 结构 | 含义 |
|---|---|
| **原材料激增** | 可能预判涨价提前囤货，也可能实际需求不足仍盲目采购 → 结合行业价格判断 |
| **产成品激增** | **最危险**。产品卖不出去，终端需求疲弱，面临大幅跌价计提 |
| **发出商品激增** | 货已发出但未确认收入/未收款 → 疑**提前确认收入** |

配合现象：**应收 + 存货同时增长 = 两头占款**。

### 7.4 应付账款 —— 反向指标（产业链地位）

`(应收 + 存货) − 应付 = 营运资本占用`

| 判据 | 地位 |
|---|---|
| **应付 > 应收 + 存货** | 占用上下游的钱做生意（**强势**，白酒、零售龙头） |
| **应收 + 存货 > 应付** | 自己垫资做生意（**弱势**） |

笔记实例：大洋生物应收 0.9 亿 vs 应付 2.7 亿 → "对成本端压得紧，销售端提价空间有限"。
"大公司和供应商之间经常发生一些应付账款，这意味着它们持有现金更长时间，
**这对改善公司现金流是有好处的**。"

### 7.5 在建工程 ⭐

`在建工程 ÷ 固定资产`，看**连续多个季度的递增趋势**。
产能扩张的前瞻指标 + 未来折旧的先行指标。

- 好：管理层看好前景，未来产能释放。
- 坏：**短债长投**。

→ **规则**：在建工程大幅增长时，必须同时检查（a）现金短债比、（b）经营现金流能否覆盖。
**三条一起恶化 = 高危。**

### 7.6 商誉 ⭐（爆雷之王）

`商誉/净资产 = 商誉 ÷ 归母净资产`

**> 30% 高危；> 20% 警惕。** 每期关注减值测试。
"商誉本质上是收购时溢出的全部价值，**应当用一种怀疑的眼光看商誉**。"
实例：上海家化 20.9%、蓝帆医疗 39.5%（悬顶之剑）、中密控股 1.5 亿（可控）。

**数据源对齐（实测）**：WeStock 的三大报表**没有 `Goodwill` 字段**，商誉只能从
`data_finsearch` / 年报附注 / 东财 F10 补。补不到就把「商誉/净资产」判为**不可评**
（打分卡该项 `null`），并在 `data_gaps` 写明「缺商誉，排雷第 5 条与该项权重无法判定」——
**不要拿「商誉」和「无形资产」凑数**，两者不是一回事。

### 7.7 未分配利润 & 资本公积 —— 家底是赚来的还是融资来的

"所有者权益里唯一值得关注的是**未分配利润**，这是公司**长期盈利情况的记录**。"

**实操算法（core 字段可算）**：`股本占净资产比 = 总股本 ÷ 归母净资产`

- 占比**低**（留存收益厚）→ 家底是长期赚出来的，PB 含金量高。
- 占比**高**（如 74%）→ 家底主要靠 IPO / 定增撑起来，低 PB 的安全含义打折扣。

配合 **§3.2 经营性 PB** 一起读：净资产里既有理财又有融资进来的股本时，低 PB 是假的。
（实例：钒钛股份股本占比 74%，2023 年筹资净流入 22.10 亿，且连续多年零分红。）

### 7.8 其他应收款 ⭐（造假高发科目）

`其他应收款占总资产比 = 其他应收款期末余额 ÷ 总资产期末余额`

**正常 < 1%~2%**，多为员工备用金、保证金、押金。

因为它"包罗万象"，容易成为**资金占用的蓄水池**和**利润调节的垃圾桶**。

| 观察项 | 正常 | 异常 |
|---|---|---|
| 占总资产比 | < 1%~2% | 占比异常高 |
| 余额趋势 | 稳定、波动小 | 持续增长，尤其**期末突击增长** |
| 前五大对象 | 备用金、保证金 | 出现**大股东、关联方、非经营性主体** |
| 账龄结构 | 短期为主 | 长期挂账，1 年以上占比高 |

**四种典型玩法（全是雷）**
1. **大股东及关联方占用**：以"临时周转"名义拆借 → 严重的公司治理问题。
2. **隐性资金占用**：以借款/往来款/代垫款名义转移给关联方，实质是**大股东抽血**。
3. **异常挂账隐藏亏损**：本应费用化的支出挂在这里，虚增当期利润。
4. **与其他应付款联动**：两者（均关联方）同时异常增加 → 可能存在复杂资金循环或虚假交易。

**一旦大股东资金链断裂，该笔款项可能血本无归，形成巨额坏账。**

## 8. 安全层（手册第七章）

### 8.1 资产负债率
`总负债 ÷ 总资产`。要**剔除合同负债**（那是预收的经营性负债，不是要还的钱）后重算，才是真实财务杠杆。
参照：西部超导 51.8%（中等）、精达股份 61%（偏高）、中船科技 81.39%（极高）。

### 8.2 有息负债 ⭐（比资产负债率更真实）
`有息负债 = 短期借款 + 一年内到期非流动负债 + 长期借款 + 应付债券`

- **看趋势，不看绝对值**：一年内大幅跳升是危险信号（西部超导 30.5 亿 → 40.7 亿）。
- **判据：毛利额 ÷ 利息费用 < 3 倍 → 公司在给银行打工。**
- 实例：蓝帆医疗有息负债 30.72 亿，壁垒业务贡献的毛利额远不足以覆盖利息。

### 8.3 营运资本与技术性资不抵债
`营运资本 = 流动资产 − 流动负债`。**为负 = 技术性资不抵债边缘**（蓝帆医疗 −4.54 亿）。

**技术性资不抵债的判定**：当「营运资本为负 + 有息负债高企 + 经营现金流为负 + 商誉高企」
同时出现时，即使所有者权益仍为正，也已实质接近爆雷。

## 9. 护城河层（手册第八章 · 决定"好"能不能持续）

护城河不直接体现在某一个科目上，而是**多个指标在时间维度上的稳定性**。

### 9.1 盈利的连贯性（5 年考察期）

> "一个能连续几年保持**稳定的 ROE 和 ROA**，拥有良好自由现金流和净利润的公司，
> 比数据不稳定的公司更有可能具有竞争优势。**连贯性是相当重要的，考察 5 年是最小的时间段。**"

→ 操作：把 **ROE / ROIC / 毛利率 / 净现比** 拉成 5 年序列，看三件事：
- 均值高低（**水平**）
- 标准差（**稳定性**）
- 有没有趋势性下移（**护城河在变窄**）

### 9.2 定价权的三重证据

1. **毛利率高且稳**（不随行业周期大幅波动）
2. **应收 / 应付结构有利**（能占用上下游资金，见 §7.4）
3. **合同负债占比高**（客户愿意先付钱，见 §2.2）

**三条占两条，基本可以确认有真实护城河。**

### 9.3 真假护城河辨别

| **虚假护城河**（最常见） | **真实护城河** |
|---|---|
| 优质产品 | 无形资产（品牌、专利、**定价权**） |
| 高市场份额 | 客户转换成本（医疗器械、精密设备） |
| 领先优势 | 网络经济 |
| 有效执行 | 成本优势（流程、位置、资源） |
| 卓越管理 | 规模优势（龙头） |

→ **财务验证**：虚假护城河的公司，毛利率会随竞争加剧而下滑
（西部超导一年掉 8.6pct）；真实护城河的公司，毛利率在行业下行期仍能守住。

### 9.4 五个指标、一次算清（报告必须上表 + 上图）

财务结果好 ≠ 有护城河；但**长期稳定的好数据是护城河的必要证据**。
固定用下面五个指标，按年铺开（≥5 年，最好 10 年）：

| 指标 | 公式 | 口径陷阱 |
|---|---|---|
| 自由现金流 FCF | 经营现金流 − **资本支出** | 资本支出 = 「购建固定资产、无形资产和其他长期资产支付的现金」，**不是**投资活动现金流净额（后者含买理财，会算出巨额负数） |
| FCF / 营收 | FCF ÷ 营业收入 | 分母用同期营业收入；FCF 为负时比值失去意义，直接写负值 |
| 净利率 | 归母净利润 ÷ 营业收入 | 要同时看扣非净利率，排除非经常性损益撑起来的利润率 |
| ROE | 归母净利润 ÷ 归母净资产 | **两端都用时点/区间同一口径**；高杠杆堆出来的 ROE 不算护城河，要配合 ROIC 看 |
| ROA | 归母净利润 ÷ 总资产 | 重资产行业天然偏低，跨行业比较无意义，只看自身趋势 |

**阈值（制造/消费类，跨行业不通用，要注明行业）**：

| 指标 | 优秀 | 一般 | 偏弱 |
|---|---|---|---|
| FCF | 连续 5 年为正 | 偶有 1 年为负 | 多年为负 / 靠融资续命 |
| FCF / 营收 | ≥ 10% | 5% ~ 10% | < 5% |
| 净利率 | 高于行业中位且 5 年标准差 < 2pct | 持平行业中位 | 低于行业中位且在下滑 |
| ROE（扣非） | ≥ 15% 且稳定 | 8% ~ 15% | < 8%，或靠杠杆 |
| ROA | ≥ 8% | 4% ~ 8% | < 4% 且下行 |

**一致性的判定规则**：5 年里 **≥4 年**同时满足 ROE 与净利率的「优秀/一般」档，
且 FCF 为正 → 判定「一致性成立」。只有一两年漂亮、其余年份忽高忽低 → **判定没有护城河**。

> 报告里必须同时给出**表格（指标 × 年份）**和**趋势图**，
> 并在表格下面写一句判定：哪几年不合格、斜率往哪走。

### 9.5 进阶：ROIC 必须跑赢 WACC

ROE 会被杠杆美化，ROIC 不会：

```
ROIC  = NOPAT ÷ 投入资本 = EBIT × (1 − 税率) ÷ (有息负债 + 股东权益 − 货币资金 − 交易性金融资产)
WACC  = Ke × E/(D+E) + Kd × (1 − 税率) × D/(D+E)
        Ke = Rf + β × ERP
```

- **投入资本要剔除超额现金和理财**，否则一家现金堆成山的公司 ROIC 会被压成个位数
  （301101 账面 ROE 只有 11.3%，但剔掉 13 亿现金后经营资本回报约 39%——这才是生意的真实回报率）。
- 参数取法：`Rf` 用 10 年期国债收益率，`ERP` 取 5%~6%，`β` 用近 2 年月度回归或同行中位数。
  **三个假设必须写进注释**，不要只丢一个数字。
- 判定：差值为正且 **> 10pct** → 强；0 ~ 10pct → 一般；
  **为负 → 公司当期在毁灭价值**，这时别急着讲护城河故事。
- 别忘了一句：**ROIC − WACC 是时点的，护城河要看它有没有在收窄**（拉 5 年）。

### 9.6 财务只是证据，最后必须回答「凭什么」

按这五类逐个判，**每一类都要给证据或明说没有**（不允许留空）：

| 来源 | 判断线索 | 典型证据 |
|---|---|---|
| 无形资产 | 品牌 / 专利 / 牌照 / 配方，能否支撑溢价且不被替代 | 毛利率高于同行且不随竞争下滑；提价后销量不掉 |
| 转换成本 | 客户换供应商要付出多大代价 | 复购率高、合同期长、嵌入式/认证类产品、医疗渠道绑定 |
| 网络效应 | 用户越多产品越好用吗 | 平台型、双边市场；制造企业通常「无」 |
| 成本优势 | 规模 / 工艺 / 资源 / 位置 | 单位成本低于同行、自产关键原料、区位独占 |
| 有效规模 | 市场容量只养得起少数玩家 | 区域垄断（机场、水务）、牌照配额 |

**五类里一条都占不到 → 直接写「无护城河」**，不要用「管理层优秀」「行业景气」凑数
（那是执行力和周期，不是护城河）。

### 9.7 行业属性判断
"有些行业赚钱就是很容易，有些行业很艰难，这是商业模式决定的。
看一下**销售收入、盈利增长率和毛利率**就能大致判断。"
→ **先选行业，再选个股**（五年规划/政策导向 → 行业空间 → 个股财务）。

## 10. 财报科目变动解读矩阵（手册第十一章）⭐⭐

> **这是整个体系里最关键的一张表。**
> 用法：**先用「收入↑↓ × 毛利↑↓」给公司定象限，再逐行核对每个科目的变动是否"讲得通"。
> 讲不通的那一格，就是管理层在骗你的地方。**
>
> 四个象限：**A = 收入↑ 毛利↑**　**B = 收入↑ 毛利↓**　**C = 收入↓ 毛利↑**　**D = 收入↓ 毛利↓**

### 10.1 现金

| 变动 | A 收入↑毛利↑ | B 收入↑毛利↓ | C 收入↓毛利↑ | D 收入↓毛利↓ |
|:--:|---|---|---|---|
| **增加** | 钱用不完，根本用不完（量价齐升，最强状态） | 坏了，公司**从成长型变成现金牛了**；理财也增加则更加坐实 | 规模缩小但产品力上升，董事长画大饼"我们走高端路线"→ 再看其他科目 | 降本增效，存钱过冬 |
| **减少** | 扩产需要钱，用掉了（良性） | 产品力下降但业务开始跑量，看看固定资产是不是扩产了 | 看看借款还扛不扛得住，可能准备过冬 | **一塌糊涂，花钱自救** |

### 10.2 应收账款周转天数

| 变动 | A | B | C | D |
|:--:|---|---|---|---|
| **增加** | "账期给点优惠，今年冲业绩，明白我意思？" | "我让利了，账期也给长了，业绩冲刺！" | "我只做高端大气上档次（不过账期可以给点优惠）" | "客户大哥，钱不用给了，先拿点货吧，我给你跪下了" |
| **减少** | 根本不愁卖，不给现钱就不卖，门口排队的客户多的是（**最强议价权**） | 我让利了，但我有怪癖，喜欢现钱 | 转型成功！不光贵还要排队 | 钱都收回来了，但未来还有潜力吗？ |

### 10.3 存货周转天数

| 变动 | A | B | C | D |
|:--:|---|---|---|---|
| **增加** | 明年还得冲刺，先屯点（良性备货） | 薄利多销，不容易啊 | 屯点高端货（**也可能低端货滞销了**，要分辨） | **产品滞销** |
| **减少** | 太畅销了，供不应求 | 薄利多销去库存成功了？ | 走高端路线，低端货不做了 | 不敢进货了，手上东西卖卖掉算了 |

### 10.4 固定资产 / 研发费用 / 销售费用

| 变动 | A | B | C | D |
|:--:|---|---|---|---|
| **增加** | 还得冲刺三年，给我扩大规模（**也可能三年内行业突然恶化而暴露**） | 走量了！未来继续走量！ | 转型！我们以后就是大牌子了 | 咬咬牙，三年后还是一条好汉 |
| **减少** | 被看穿了？难道是企业最高光时刻（**投入停止 = 增长见顶信号**） | 现金牛了，躺平了躺平了 | 就卖毛利高的算了，日子滋润就行 | **收缩保平安** |

### 10.5 应付账款周转天数

| 变动 | A | B | C | D |
|:--:|---|---|---|---|
| **增加** | 不仅客户跪着，供应商也跪着（**两头通吃，最强**） | 我治不了客户，还治不了供应商？ | 我高端货，不接我单子我找别人 | 快完蛋了，供应商让让我吧，我寄了你也没好日子过 |
| **减少** | 产业链都不错，上游比我牛 | **两头欺负我，我夹在当中算什么东西** | 缩小规模，不需要这么多供货了 | 让本不富裕的家庭雪上加霜 |

### 10.6 短期借款 / 长期借款

| 科目 | 变动 | A | B | C | D |
|---|:--:|---|---|---|---|
| 短期借款 | **增加** | 结合固定资产及现金看：要么扩产冲刺，要么给银行小妹一点业务 | 扩产 / 被供应商和客户两头压榨，借点借点 | 日子也不好过，供应商客户都欺负我 | **江湖救急！不借的话，之前借的钱也不还了！** |
| 短期借款 | **减少** | 不缺钱，根本花不完 | 现金牛不缺钱，要不买点理财？ | 还掉，小本经营 | 利率太高，理财赎回还掉点，反正没未来了 |
| 长期借款 | **增加** | 不借白不借，反正利息低 | 扩产买设备不要钱吗！研发高毛利产品不要钱吗！ | 画饼：我们只是阵痛，长期看好 | **"今天救了我，三年后一定报答你"** |
| 长期借款 | **减少** | 银行小妹也不好使了，不缺钱 | 现金牛躺平了 | 量没跑起来，不需要这么多钱 | 长期借款 3 个点？我理财才 1 个多点利息 |

### 10.7 合同负债 ⭐

| 变动 | A | B | C | D |
|:--:|---|---|---|---|
| **增加** | 未来还有大订单，继续冲（**最健康的一格**） | 跑量计划通？ | 虽然现在收入下滑，但未来可期！ | 画饼：行业寒冬迎来拐点（**实际可能只是最后的狂欢**） |
| **减少** | 坏了，**潜力下降了** | 到拐点了？ | 下一步毛利也要下滑？ | **全完了** |

### 10.8 矩阵的经典组合用法

- **收入↑毛利↓ + 应收周转天数↑ + 短期借款↑ + 现金↓** = **赊销冲量 + 借钱垫资**（精达股份型）
- **收入↓毛利↓ + 现金↓ + 短期借款↑ + 合同负债↓** = **花钱自救，全完了**（蓝帆医疗型）
- **收入↑毛利↑ + 应收周转天数↓ + 应付周转天数↑ + 合同负债↑** = **两头通吃的真龙头**（茅台型）

**核心一句话**：把"孤立看一个科目"变成"科目组合讲故事"。

## 11. 五大排雷指标联动框架 + 排雷三步法（手册第十二章）⭐

### 11.1 五大排雷指标

| # | 指标 | 核心公式 | 要抓的问题 |
|:--:|---|---|---|
| 1 | **净现比** | 经营现金流净额 ÷ 归母净利润 | **利润有没有现金支撑** |
| 2 | **应收占收入比 / 周转 / 增速差** | 应收 ÷ 营收；365 ÷ 周转率 | **收入有没有变成回款** |
| 3 | **存货周转天数 / 结构 / 增速** | 365 ÷ (营业成本 ÷ 平均存货) | **库存是不是在积压** |
| 4 | **其他应收款占总资产比** | 其他应收款 ÷ 总资产 | **资金有没有被占用** |
| 5 | **销售/管理/研发费用率 + 费用增速 vs 收入增速** | 费用 ÷ 营收 | **费用效率与确认是否异常** |

一句话概括：**利润的含金量、收入的真实性、库存的健康度、资金的独立性、费用的合理性。**

### 11.2 五指标联动定性表（单一指标异常不足以定性）

| 风险类型 | 指标组合 |
|---|---|
| **收入虚增** | 应收增速 >> 收入增速 **+** 净现比持续偏低 **+** 存货周转恶化 |
| **资金占用** | 其他应收款异常高企 **+** 关联方往来频繁 **+** 经营现金流持续为负 |
| **库存危机** | 存货增速 >> 收入增速 **+** 产成品占比上升 **+** 跌价计提不足 |
| **利润操纵** | 净现比持续偏低 **+** 费用资本化比例上升 **+** 坏账/跌价计提比例下降 |
| **商业模式恶化** | 净现比下降 **+** 应收周转拉长 **+** 费用率上升（**三重恶化**） |

### 11.3 排雷三步法

1. **看趋势**：至少拉 **3~5 年**数据，观察连续变化——**单年波动意义有限**。
2. **比同行**：与可比公司横向对比，判断偏离是否合理（剔除行业特性与商业模式差异）。
3. **追根源**：发现异常后深入**财报附注**，查看科目明细、会计政策变更、关联方交易，
   **找到异常背后的真实原因**。

## 13. 打分卡与结论映射（手册九·二）

**每看一家公司填一次，作为 §0 七步流程的收口。得分只能是 −2 / −1 / 0 / +1 / +2。**

| 维度 | 指标 | 权重 |
|---|:--:|:--:|
| 真伪 | 经营现金流 + 净现比 | ×3 |
| 真伪 | 扣非 vs 归母缺口 | ×2 |
| 趋势 | ① 毛利率环比改善 | ×2 |
| 趋势 | ② 合同负债/订单增长 | ×2 |
| 质量 | ③ 应收增速差（反向） | ×2 |
| 质量 | 三流组合阶段 | ×2 |
| 安全 | ① 现金短债比 | ×3 |
| 安全 | 商誉/净资产（反向） | ×2 |
| 安全 | 有息负债趋势（反向） | ×2 |
| 安全 | 其他应收款/总资产（反向） | ×2 |
| 质量 | 存货周转天数 + 产成品占比（反向） | ×1 |
| 质量 | 费用增速 vs 收入增速（反向） | ×1 |
| 交叉 | **§10 矩阵"故事讲得通吗"** | ×3 |
| 性质 | ROIC vs WACC + 5 年稳定性 | ×3 |
| 性质 | ROE 杜邦来源（杠杆型扣分） | ×1 |
| 价格 | PE 梯度 + PB（经营口径）+ PEG | ×2 |

**满分 = 各项权重 × 2 之和**（每项满分 +2）。

**结论映射：三维矩阵**（报告 stance 必须由此推出，不许拍脑袋）

三个轴，按顺序判：

1. **有没有一票否决**（第 1 步现金流 / 第 4 步安全高危、第 6 步故事讲不通）；
2. **得分率**（实算加权分 ÷ 可评项满分，缺项不计入分母）；
3. **估值档位**（PEG + 经营口径 PB 分位）。
   第七节的 PE/PB/PS 三个分位如果方向不一致（例如 PB 在 8% 分位、PE 在 60% 分位），
   **先查分母有没有被一次性收益或减值污染，再定档**；定不了就按更保守的一档。

| 否决项 | 得分率 | 估值 | stance |
|---|:--:|---|---|
| 命中 | — | — | **不看好**（一票否决，不管后面多漂亮） |
| 无 | ≥ 70% | PEG ≤ 1.2 或经营 PB 分位 < 30% | **看好** |
| 无 | ≥ 70% | PEG 1.2 ~ 2.0 | **看好但等安全边际**（"好公司，但不是好股票"） |
| 无 | ≥ 70% | PEG > 2.0 | **看好但等安全边际**，并给出回调区间 |
| 无 | 50% ~ 70% | 任意 | **谨慎观望**（给出明确的触发条件） |
| 无 | < 50% | 任意 | **不看好**（基本面不过关，估值便宜也不买） |
| 无 | — | — | 可评项 < 8 项（数据缺口过大）→ **谨慎观望**，并单列数据缺口 |

**缺项处理（重要）**：拿不到数据的项**不记 0 分，而是从分母剔除**。
0 分是「中性判断」，缺数据是「不知道」——混起来会把数据不全的公司判成经营变差。
报告里必须写清「本次可评 11 / 16 项，得分率按 11 项计算」。

**边界情形**：落在两档之间时，选**更保守**的一档，并在 `conclusion` 里一句话说明理由
（例如「第 5 步 ROIC 只比 WACC 高 5pct，谈不上漂亮，所以走保守档」）。

**写 ``watchlist`` 的要求**：每条必须落到具体指标 + 具体阈值 + 观察频率，
不允许出现"关注行业变化"这类空话。
