# 指标体系速查（用于企业信息解读报告）

> 完整版见《企业财务分析指标体系手册》。本文件是**执行报告时的精简版**，
> 只保留能拿到数据后直接判定的部分。
> 三条铁律：**现金流 > 利润；趋势 > 时点；结构 > 总量。**

---

## 0. 七步研判流程（报告的主干）

```
1 验真伪   经营现金流是否为正、净现比是否健康、扣非与归母缺口大不大
2 看趋势   毛利率环比改善？合同负债（订单）在涨吗？营收与净利的四种组合
3 查质量   应收增速差、存货、在建工程、三流组合处在哪个阶段
4 排雷     现金短债比、净现比、应收增速差、速动比率、商誉、有息负债、其他应收款
5 定性质   ROE/ROA/ROIC 三件套、杜邦拆解、ROIC 是否大于资本成本、5 年连贯性
6 交叉验证 用「收入↑↓ × 毛利↑↓」矩阵，检查每个科目的变动是否讲得通
7 问价格   静态/滚动/动态 PE 梯度、PB（剔理财与商誉）、PEG 是否透支未来
```

**一票否决规则**：第 1 步（现金流）或第 4 步（安全）任一高危 → 直接否定；
第 6 步故事讲不通 → 直接否定，不必再算估值。

---

## 1. 利润有无现金支撑（净现比）

`净现比 = 经营活动现金流净额 ÷ 归母净利润`　（现金流 + 利润 两张表）

| 区间 | 判定 |
|:--:|---|
| > 1.0 | 优秀，甚至收回往期欠账 |
| 0.7 ~ 1.0 | 健康 |
| 0.3 ~ 0.7 | 警惕，利润与现金脱节 |
| < 0.3 或负 | 危险，可能收入虚增 / 提前确认收入 |

交叉验证用 **扣非净现比 = 经营现金流 ÷ 扣非净利润**。
连续多年偏低 = 商业模式本身赚不到现金；单年骤降要分是收入端回款慢还是支出端占用增加。

## 2. 订单前瞻（合同负债）

`订单代理 = 合同负债 + 预收款项`（资产负债表）
`同比 = (本期 ÷ 上年同季 − 1) × 100`；`规模 = 本期 ÷ 营业总收入 TTM × 100`

**同比 ≥ 20% 且 规模 ≥ 2% → 是；否则 → 否。**
时点值，要看 3–4 个季度的趋势；经销商打款性质的预收要打折看待。

## 3. 毛利率环比改善

`GM = (营业收入 − 营业成本) ÷ 营业收入`

三条件同时成立才算"是"：
1. 最近 2 个单季严格递增：`GM[t−1] < GM[t]`
2. 最新一季营收环比不为负：`Rev[t−1] ≤ Rev[t]`（排除靠砍业务瘦出来的好看）
3. 最新单季高于上年同季：`GM[t] > GM[t−4]`（剔除季节性）

## 4. 靠不靠赊账换增长（应收增速差）

`应收增速差 = 应收增速 − 营收增速`

- 最近 2 个年报均 > +15 个百分点 → **高危**
- 只有最新一年 > +15 个百分点 → **关注**

配套排查：应收占收入比、周转天数是否年年拉长、前五大客户集中度、1 年以上账龄占比、
坏账计提政策是否显著松于同行、应收账款是否突然大量转为应收票据（科目腾挪）。

## 5. 短期偿债

| 指标 | 公式 | 阈值 |
|---|---|---|
| 现金短债比 | 货币资金 ÷ (短期借款 + 一年内到期非流动负债) | < 1.0 紧张；< 0.5 高危 |
| 速动比率 | (流动资产 − 存货) ÷ 流动负债 | < 0.7 关注 |
| 流动比率 | 流动资产 ÷ 流动负债 | < 1.5 留意（重资产行业可放宽） |
| 营运资本 | 流动资产 − 流动负债 | 为负 = 技术性资不抵债边缘 |

分子建议用「货币资金 + 交易性金融资产」，并剔除受限的票据保证金。

## 6. 有息负债（比资产负债率更真实）

`有息负债 = 短期借款 + 一年内到期非流动负债 + 长期借款 + 应付债券`

- **看趋势不看绝对值**：一年内大幅跳升（如 30 亿 → 40 亿）是危险信号。
- 算 **毛利额 ÷ 利息费用**，低于 3 倍说明公司在给银行打工。
- 资产负债率建议剔除合同负债后重算（合同负债是经营性负债，不是要还的钱）。

## 7. 造假高发科目

| 科目 | 正常 | 危险信号 |
|---|---|---|
| 其他应收款 | 占总资产 < 1%~2%，多为备用金/保证金 | 占比异常高；对象含大股东或关联方；长期挂账；与其他应付款同时异常增加 |
| 存货 | 增速 ≤ 收入增速 | 增速远超收入；**产成品占比上升**（最危险）；发出商品激增；跌价计提不足 |
| 商誉 | 占净资产 < 10% | **> 20% 警惕，> 30% 高危** |
| 在建工程 | 与现金流匹配 | 大幅增长且短期借款同时上升 = 短债长投 |
| 研发费用 | 资本化比例稳定 | 资本化比例突然上升 / 销售费用率异常下降 = 延后费用美化利润 |

## 8. 盈利能力三件套

| 指标 | 分母 | 看什么 |
|---|---|---|
| ROE | 净资产（股东的钱） | **高杠杆会虚高**，>= 15% 才算优秀（连续 3 年） |
| ROA | 总资产 | 剔一部分杠杆影响后的资产回报 |
| ROIC | 股东的钱 + 借的钱 | **生意本身的赚钱率**，剔除了杠杆 |

**排序规律**：正常盈利时 `ROE > ROIC > ROA`；亏损时三者反转；无负债时三者接近。
`ROE >> ROIC` → 杠杆撑起来的盈利，要扣分。

**杜邦拆解**：`ROE = 净利率 × 资产周转率 × 权益乘数`
靠净利率 = 最优质（茅台）；靠周转率 = 次优（沃尔玛）；**靠杠杆 = 风险高（银行）**。

**及格线**：`ROIC > 资本成本`。资本成本保守取 **5.5%**（对照国债/理财收益），
经营稳健的公司可取 6%~8%。**ROE 高但 ROIC < 资本成本 = 表面上赚钱、实际毁灭价值。**

## 9. 估值

| 指标 | 用法 |
|---|---|
| 静态 PE | 按去年利润算贵不贵 → 看历史 |
| 滚动 PE (TTM) | 按最近 12 个月算 → 看当下，最常用 |
| 动态 PE | 按预测利润算 → 看未来，**预期不是事实** |
| PB | **周期股 / 金融股优先看 PB**；要剔理财和商誉算「经营性 PB」 |
| PS | 暂时不盈利但营收高增长时用，**必须配合净利率看** |
| 股息率 | 高分红是现金流的硬证据；但高股息 + 低 ROIC = 现金牛而非成长股 |
| PEG | 接近 1 匹配，> 1.5 偏贵，< 0.8 偏便宜；**仅适用稳定成长股** |

**历史分位**：PE/PB 处于近 5–10 年区间 < 20% 为低估，> 80% 为高估。

**PE / PB 组合**：
- PB 低 + PE 低 → 资产质量没问题时，安全边际最高
- PB 高 + PE 低 → 市场认可资产，当前盈利被低估
- PB 低 + PE 高 → 资产便宜但盈利弱
- PB 高 + PE 高 → 估值泡沫，或刚计提完大额减值

## 10. 三流组合（企业处在什么阶段）

| 经营 | 投资 | 筹资 | 解读 |
|:--:|:--:|:--:|---|
| + | − | − | 成熟现金牛：主业造血，投资回收，还债分红 |
| + | −− | + | 扩张期：主业造血但不够，借钱扩产 |
| − | − | ++ | ⚠️ **危险**：主业失血还在投，全靠外部输血续命 |
| − | −− | + | 烧钱转型：用融资的钱赌未来 |
| − | + | − | 收缩求生：卖资产还债 |

## 11. 排雷组合信号（命中即标红）

1. 净利大增 + 扣非亏损或微利 + 经营现金流恶化
2. 营收增 + 净利不增 + 应收大增 + 短期借款大增
3. 经营现金流 − + 投资现金流 − + 筹资现金流 +
4. 现金 < 短期借款 + 在建工程持续扩张（短债长投）
5. 商誉占净资产 > 20%
6. 有息负债快速攀升 + 毛利下滑 + 下游回款慢
7. 高毛利业务收入占比很低（故事讲的高端，赚钱靠低端货）
8. 静态 PE 低而动态 PE 高（机构预期未来利润下滑）
9. PB 低但净资产里大量是理财或未分配利润（安全垫是假的）
10. ROE 高而 ROIC 低（利润是杠杆撑的）
11. 周期股用低 PE 判断便宜（周期顶部 PE 会假便宜）
12. 费用增速 > 营收增速，持续 2 年以上
13. 营运资本为负 + 有息负债高（技术性资不抵债边缘）
