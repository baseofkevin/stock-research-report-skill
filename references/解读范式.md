# 凯文的企业信息解读范式

> 提炼自私人笔记 B0001–B0007（西部超导、上海家化、奥飞娱乐、智莱科技、大洋生物、恒星科技、中密控股、建业股份、精达股份、当虹科技、华能蒙电、新亚强、厚普股份、安彩高科、盟固利、蓝帆医疗、久之洋）。
> **目的：让 AI 写出的报告在结构、口径、语气上与你自己的笔记一致。**

---

## 一、固定六段式结构

每篇解读都按这个顺序展开，**顺序不要变**——它是你的思考路径：

```
1. 股价位置   → 从季K线级别看现在在哪儿，有没有透支
2. 估值       → 静态/滚动/动态 PE、PB、股息率，贵不贵
3. 生意本身   → 卖什么、行业地位、有没有壁垒、下游需求和政策
4. 财务体检   → 最新一期财报的营收/净利/扣非/毛利/现金流 + 资产负债表明细
5. 综合分析   → 定性结论，好不好、贵不贵、看不看好
6. 跟踪清单   → 后续要盯哪几个数据才能验证判断
```

**为什么是这个顺序**：先定位置（不追高）→ 再看贵贱（安全边际）→ 再看生意（有没有资格买）→ 再看财务（现在经营得怎么样）→ 综合定性 → 留后手。是"先看能不能亏，再看能不能赚"。

---

## 二、每段的写法模板

### 第 1 段 · 股价位置

必答三件事：**历史区间（最高/最低点在哪年）→ 当前在区间的什么位置 → 上方有没有均线压力**。

```
从季 K 线来看，{年份} 年股价最高 {X} 元，{年份} 年最低到过 {Y} 元，
{最近牛市} 期间最高冲到 {Z} 元，目前 {现价} 元处于 {高位/中部/底部}{微调}位置。
MA120 / MA250 在{头顶压着|已站上}，{意味什么}。
```

定性词汇库：`历史底部区域` `年内中位` `回调反抽中间位置` `冲高后腰斩的小反弹` `深度回撤` `牛市高点回调中段` `长期均线层层封锁` `尚未突破长期均线压制`

> 笔记原文示例：「从季 K 线来看，股价处于历史低位」「股价处于上市 3 年来的低位」「在 MA250 的重压区」「历次牛市驱动，都能拉升一波，但拉升的高度越来越低」

### 第 2 段 · 估值

**三种 PE 必须一起报，并且要解读它们的"梯度"**（这是你最有辨识度的习惯）：

```
静态 PE {a}，滚动 PE {b}，动态 PE {c}，
说明 {机构预期未来利润大幅下滑|是因为去年亏损今年转正扭曲了同比|市场预期今年赚更多}。
PB {d}，{贴现/溢价}交易，股息率 {e} {有吸引力/不性感}。
```

三条梯度规律（背下来直接用）：

| 梯度 | 含义 |
|---|---|
| 静态高、滚动低 | 最近确实赚更多了，业绩在改善 |
| 滚动高、动态低 | 机构预期未来大幅改善——**注意：预期不是事实** |
| 静态低、动态高 | 机构预期未来利润下滑 ⚠️ |

配套必查：**估值贵不贵，一定要和历史分位、同业、PEG 比**。
周期股（煤炭、光伏、化工）**PE 会失真，改用 PB**。

### 第 3 段 · 生意本身

要回答四个问题，缺一不可：
1. 产品是什么，下游用在哪儿（说人话，别抄招股书）；
2. **各业务占营收多少、毛利多少**——永远要拆开，不能只看整体；
3. 行业处于上行还是下行，有没有政策/产业趋势支持；
4. 真护城河还是假护城河（对比龙头：规模、毛利、定价权）。

> 关键习惯：**高毛利业务如果收入占比很低，等于没有。**
>
> 正确写法是把产品结构和毛利率并排摆出来，然后立刻下结论，例如：
> 「占营收 56% 的金属制品毛利仅 7%，占营收 33% 的有机硅毛利 23%——
> 这说明支撑公司盈利的其实只是一小块业务。」
>
> 反面案例（笔记里的蓝帆医疗）：有壁垒的器械业务毛利 64%，但只占收入 30%；
> 真正撑营收的仍是毛利 20% 的一次性手套，且器械贡献的毛利额远不足以覆盖 30.72 亿有息负债的利息。

### 第 4 段 · 财务体检

固定句式：

```
从 {20XX} 年 {半年报/年报} 来看，{各项指标的大方向}。
具体来看：营业收入 {X} 亿，同比 {±Y}%；归母净利润 {A} 亿，同比 {±B}%；
扣非净利润 {C}，同比 {±D}%；综合毛利率 {E}%，同比 {±F} 个百分点；
经营活动现金流净额 {G} 亿，同比 {±H}%，{是不是真的收到了钱}。
```

**必须给的补充面**：货币资金、有息负债/短期借款、长期借款、应收账款、存货、应付账款、
在建工程、商誉、未分配利润、资本公积、资产负债率。
**并且一定要算派生比率**，而不是只报绝对值：

| 派生比率 | 算给谁看 |
|---|---|
| 理财/交易性金融资产 ÷ 总资产 | 说明现金没处花，价值损耗 |
| 商誉 ÷ 净资产 | 悬顶之剑有多大 |
| 有息负债 ÷ 账上现金 | 偿债压力 |
| 利息费用 vs 主营毛利额 | 是不是在给银行打工 |
| 短期借款 vs 在建工程 | 有没有"短债长投" |
| 应收 + 存货 − 应付 | 营运资本占用（是不是自己在垫资） |
| 未分配利润 vs 净资产 | 家底是赚来的还是融资来的 |

### 第 5 段 · 综合分析

**要给明确结论，不要骑墙**。常用结语库：

`所以，这个企业不看好` / `当前估值偏高，可以再等等，等有一定的安全边际再出手比较合适` /
`还需要后续业绩的验证` / `关键看 {具体数据} 是否 {改善/企稳}` /
`这个企业不性感、不激动，预期不高，但可以赚周期加分红的钱` /
`赚的是周期回暖加分红回报的钱，股价弹性有限`

推演句式（用得最多）：
- `这么看来，{结论}`
- `这也说明 {一件事的两面}`
- `从这些数字来看，1. … 2. … 3. …`
- `虽然在 xxx 概念加持下，但 {真相}`
- `问题就在于：{核心矛盾}`
- `后续关键看 {某个变量}，如果 {情形A} 将 {结果A}，如果 {情形B} 将 {结果B}`

### 第 6 段 · 跟踪清单

每条要**具体到指标和数据**，不能写"关注行业变化"这种废话：

```
后续跟踪：1. {具体指标} 是否延续 {改善/恶化}；
         2. {某个事件/产能/政策} 的落地节奏；
         3. {财务验证点}——若连续 X 个季度 xxx，则判断需要修正。
```

## 三、语气与节奏

- **用数据说话，不用形容词堆砌**。每个判断后面必须跟数字。
- **承认不确定**：`会不会再涨起来，现在说不准，但…`、`有待进一步验证`、`还要继续观察`。
- **有价值观输出但不煽情**：可以直接说 `表现了我们 A 股企业的通病`、`私企老板做企业很累风险也高`——**但这类主观感慨放在文末"另外"里，不要混进正文的财务分析**。正文保持冷静。
- **长短句交错**，善用口语化的破折号和括号补充：`帝3年内）。
- **不要写**：姹紫嫣红的套话，如"值得 XX 关注""未来可期""助力 XX 腾飞"；也不要写"综上所述""本文不构成投资建议"之外的客套。

## 四、几条硬规矩

1. **每个比率都要同时给分子和分母的绝对额**，只给百分比等于没说。
2. **同比必须标清楚是对哪一年同期**，尤其是半年报 vs 半年报。
3. **三项都不能忘：扣非净利、经营现金流、商誉**——这是你历史上抓假信号最有效的三项。
4. **发现矛盾要指出来**：净利大增但现金流恶化、毛利率升但应收暴增……**矛盾点才是结论**。
5. **绝对禁止编造数据**。数据源没有的字段，写"暂无披露"，不要用常识或训练记忆补齐。
6. **区分"事实"和"推测"**：财报数字是事实，管理层表态和机构预期是推测，要在措辞上分开
   （机构预测写"隐含的假设是…"，自己的判断写"这么看来…"）。
